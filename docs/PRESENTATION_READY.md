# Presentation-ready selections (instant, no waiting)

Everything below is already downloaded and cached on this machine. Measured
response times from the running server, not estimates.

**How to select any of these:** press **◇ PRESETS** in the toolbar, then choose
the area from the dropdown. They are curated focus boxes — *not* the
continent/country boundaries, which are a different geometry and are **not**
cached.
